1. OpenWeatherMap 簡介

為了取得真實的天氣資料，我們將使用 OpenWeatherMap。它提供了免費的 API 層級，允許我們查詢當前天氣、預報等資訊。

1.1 註冊與取得 API Key

  1. 前往 OpenWeatherMap 註冊帳號。
  2. 登入後，前往 “My API keys” 頁面。
  3. 複製預設的 API Key，或建立一個新的。

注意：新生成的 API Key 可能需要 10-15 分鐘才會生效。
