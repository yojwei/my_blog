  • 官方文件

快速安裝 uv

  • Windows (PowerShell):

  • macOS / Linux：

  • 驗證安裝：uv --version

管理 Python 版本

  • uv python list：列出可安裝的 Python 版本
  • uv python install 3.14：安裝 Python 3.14

建立 Flask 專案結構

  • uv init flask_demo --python 3.14
    • 初始化專案
    • 指定版本為 3.14
  • uv add flask：安裝 Flask 依賴

Git 版本控制初始化

  • git add -A & git commit -m "Initial commit"：
    • 將專案加入版本控制並提交初始版本

  • 新增一個 app.py

  • 啟動伺服器：
