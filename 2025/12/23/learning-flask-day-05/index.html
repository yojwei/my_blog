1. 什麼是 Jinja2？

Flask 預設使用 Jinja2 作為模板引擎。它允許我們在 HTML 中嵌入 Python 邏輯，動態生成網頁內容。
Jinja2 的核心概念是將「資料」與「呈現邏輯」分離，讓後端專注於處理資料，前端專注於頁面結構。

2. 模板基礎語法

Jinja2 主要有三種語法結構：

2.1 變數 (Variables)

用於輸出變數的值。

2.2 控制結構 (Control Structures)

用於邏輯控制，如迴圈 (for) 和條件判斷 (if)。

  • 條件判斷 (If Statements)
  • 迴圈 (For Loops)

2.3 註解 (Comments)

用於在模板中添加註解，這些內容不會顯示在最終的 HTML 中。

2.4 過濾器 (Filters)

用於修改變數的顯示方式。

3. 模板繼承 (Template Inheritance)

這是 Jinja2 最強大的功能之一。我們可以定義一個基礎模板 (base.html)，包含所有頁面共用的部分（如導航列、頁尾、CSS/JS 引用），然後讓其他頁面繼承它。
