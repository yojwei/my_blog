Day 02 - 建立基本 Flask Layout

這是 30 天學習 Flask 計畫 - Weather App 的 Day 2 詳細內容
source code

1. 專案結構介紹

2. Application Setup

新增環境變數範本

  • 新增 dotenv 依賴：uv add python-dotenv

  • 在專案根目錄新增 .env.example

  • 在 .gitignore 中加入 .env，避免將敏感資訊提交到版本控制

  • 使用 .env.example 作為範本，建立實際的 .env 檔案來存放環境變數

建立 Application Factory

  • 在 flask_weather/__init__.py 中建立應用程式工廠

  • 建立配置管理模組 flask_weather/config.py

  • 在 app.py 中啟動應用程式

  • 驗證應用程式啟動：uv run flask run

新增路由、工具函數和前端資源

  • 建立路由模組 flask_weather/routes/__init__.py
  • 建立工具函數模組 flask_weather/utils.py
  • 在 flask_weather/static/ 中新增 CSS 樣式檔 style.css
  • 在 flask_weather/templates/ 中建立基礎模板 base.html

初始化測試模組

  • 在 tests/ 目錄中建立測試套件初始化檔 __init__.py
  • 建立應用程式測試檔 tests/test_app.py，準備撰寫單元測試
  • 後續將使用 pytest 來撰寫和執行測試
