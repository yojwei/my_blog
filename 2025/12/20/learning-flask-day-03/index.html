Day 03 - 路由與請求處理 (Routing & Request Handling)

這是 30 天學習 Flask 計畫 - Weather App 的 Day 3 詳細內容
source code

1. 目標

掌握 Flask 的路由系統，學習如何處理不同的 HTTP 方法（GET、POST），
並利用動態路由參數與請求物件（Request Object）來實作基礎的天氣查詢功能。

2. URL 路由基礎

在 Flask 中，路由是透過 @app.route() 裝飾器來定義的。它負責將 URL 對應到特定的 Python 函數（稱為 View Function）。

3. HTTP 方法：GET 與 POST

預設情況下，路由僅響應 GET 請求。若要處理表單提交（例如搜尋城市），我們需要顯式指定 methods 參數。

  • GET：用於獲取資料（如：顯示搜尋表單）。
  • POST：用於提交資料（如：送出搜尋關鍵字）。

4. 請求物件 (Request Object) 詳解

Flask 的 request 物件包含了所有客戶端發送的請求資訊：

  • request.args：獲取 URL 查詢參數（GET 請求，如 ?q=Taipei）。
  • request.form：獲取表單內容（POST 請求）。
  • request.method：當前的請求方法。

範例：結合 HTTP 方法與請求物件

5. 動態路由參數

我們可以使用 <variable_name> 語法來建立動態 URL，這對於「城市天氣頁面」非常實用。

6. 錯誤處理 (Error Handling)

使用 @app.errorhandler 裝飾器可以自定義錯誤頁面（如 404 找不到網頁），提昇使用者體驗。
