為什麼使用 class 模式？

  • class 模式讓我們完全控制何時切換 Dark Mode
  • 可以使用 Alpine.js 管理狀態並儲存到 localStorage
  • 比 media 模式（自動跟隨系統設定）更靈活

📝 base.html <html> 標籤程式碼變更：

程式碼解析：

  1. x-data="{ darkMode: ... }"：初始化 Dark Mode 狀態，從 localStorage 讀取
  2. :class="{ 'dark': darkMode }"：當 darkMode 為 true 時，在 html 加上 dark class
  3. x-init="$watch('darkMode', ...)"：監聽狀態變化，自動儲存到 localStorage
  4. transition-colors duration-300：平滑的顏色過渡效果

3. PWA 基礎配置 (Progressive Web App)

讓網頁可以像原生 App 一樣安裝在手機桌面上，提供離線瀏覽和更好的使用體驗。

3.1 建立 manifest.json

在 static/ 目錄下建立 manifest.json：

manifest.json 屬性說明：

  • name: 應用程式完整名稱（安裝時顯示）
  • short_name: 簡短名稱（圖示下方顯示）
  • start_url: 啟動 URL
  • display: 顯示模式（standalone 讓它像原生 App）
  • background_color: 啟動畫面背景色
  • theme_color: 工具列顏色
  • icons: 各種尺寸的圖示（必須提供 192x192 和 512x512）
  • purpose: "maskable": 讓圖示適應不同形狀（圓形、方形等）

3.5 測試 PWA

  1. 使用 Chrome DevTools 測試：

    • 打開 Chrome DevTools (F12)
    • 切換到「Application」標籤
    • 檢查「Manifest」是否正確載入
    • 檢查「Service Workers」狀態
    • 使用「Lighthouse」進行 PWA 審核

  2. 手機測試：

    • 在 Chrome/Safari 開啟應用程式
    • 點擊「新增至主畫面」或「安裝應用程式」
    • 從主畫面啟動，確認以 standalone 模式執行

4. 本日實踐重點

4.1 實作檢查清單

Dark Mode 實作：

  • ✅ 配置 Tailwind darkMode: 'class'
  • ✅ 使用 Alpine.js 管理 Dark Mode 狀態
  • ✅ 在 <html> 加入動態 dark class
  • ✅ 使用 localStorage 儲存使用者偏好
  • ✅ 加入 Dark Mode 切換按鈕
  • ✅ 更新所有元件支援 dark: 樣式
  • ✅ Chart.js 支援 Dark Mode

PWA 實作：

  • ✅ 建立 manifest.json
  • ✅ 產生各種尺寸的圖示（72x72 ~ 512x512）
  • ✅ 在 base.html 引入 manifest
  • ✅ 加入 Apple/MS 相關 meta tags
  • ✅ （可選）建立 Service Worker 支援離線功能
  • ✅ 使用 Lighthouse 測試 PWA 分數

4.2 學習重點

  1. Alpine.js 狀態管理：使用 x-data、x-init、$watch 管理 Dark Mode
  2. Tailwind Dark Mode：dark: 前綴的使用方式
  3. localStorage API：儲存和讀取使用者偏好
  4. PWA Manifest：讓網頁可安裝的關鍵配置
  5. Service Worker：實現離線快取和推送通知
  6. 響應式圖示：purpose: "maskable" 讓圖示適應不同平台

4.3 效能優化建議

  1. **使用 CSS transition**：讓 Dark Mode 切換更平滑
  2. 預載關鍵資源：在 <head> 使用 <link rel="preload">
  3. 延遲載入非關鍵 CSS：使用 media="print" onload="this.media='all'"
  4. Service Worker 快取策略：網路優先或快取優先依需求選擇

實踐時間：60-90 分鐘

  1. 配置 Tailwind Dark Mode 並實作切換按鈕（20 分鐘）
  2. 更新所有元件支援 Dark Mode 樣式（25 分鐘）
  3. 建立 manifest.json 和產生圖示（20 分鐘）
  4. （可選）實作 Service Worker（25 分鐘）
