source code

1. 為什麼需要資料庫遷移 (Migrations)？

在 Day 10 中，我們使用 db.create_all() 來建立資料庫。但在實際開發中，資料庫結構會不斷改變（例如新增欄位、修改資料表）。
如果每次修改都要刪除舊資料庫重建，資料就會遺失。Flask-Migrate (基於 Alembic) 讓我們可以像 Git 管理程式碼一樣，管理資料庫結構的變更歷史。
