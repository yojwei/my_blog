1. 什麼是 Jinja2？

Flask 預設使用 Jinja2 作為模板引擎。它允許我們在 HTML 中嵌入 Python 邏輯，動態生成網頁內容。
Jinja2 的核心概念是將「資料」與「呈現邏輯」分離，讓後端專注於處理資料，前端專注於頁面結構。

1. 藍圖 (Blueprints) 基本概念

當 Flask 應用程式變大時，將所有路由寫在一個檔案中會導致程式碼難以維護。藍圖 (Blueprint) 是 Flask 提供的一種組織程式碼的方式，它允許我們：

  • 分離關注點：將功能相近的路由分組（如：認證、天氣查詢、主要頁面）。
  • 可複用性：藍圖可以在不同的專案中重複使用。
  • 避免循環引用：在 Application Factory 模式中，藍圖是解決 import 衝突的最佳方案。
