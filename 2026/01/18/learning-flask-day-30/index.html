Day 30 - 部署到 Zeabur 雲端平台

這是 30 天學習 Flask 計畫 - Weather App 的 Day 30（最終章）
source code

恭喜你來到最後一天！今天我們要將應用程式部署到 Zeabur 雲端平台，讓全世界都能存取你的天氣應用。

1. 為什麼選擇 Zeabur？

Zeabur 是一個現代化的 PaaS（Platform as a Service）平台，提供：

  • ✅ 自動部署：連結 GitHub 後自動偵測變更並部署
  • ✅ 零配置服務：一鍵新增 PostgreSQL、Redis 等服務
  • ✅ 自動注入環境變數：服務間自動建立連線
  • ✅ 免費方案：適合個人專案與學習
  • ✅ 台灣團隊開發：有中文介面與客服支援

2.2 準備環境變數清單

整理好需要設定的環境變數：

變數名稱 說明 如何取得
FLASK_ENV 環境模式 設為 production
SECRET_KEY Flask 加密金鑰 用 python -c 'import secrets; print(secrets.token_hex(32))' 產生
OPENWEATHER_API_KEY OpenWeather API Key 從 OpenWeatherMap 取得
DATABASE_URL PostgreSQL 連線 Zeabur 自動注入
RATELIMIT_STORAGE_URI Redis 連線 手動設定為 ${REDIS_CONNECTION_STRING}

3. 部署到 Zeabur

3.1 註冊並連結 GitHub

  1. 前往 Zeabur 註冊帳號（可使用 GitHub 直接登入）
  2. 點選右上角頭像 → Settings → GitHub
  3. 點選 Connect GitHub 並授權 Zeabur 存取你的 Repositories

3.2 建立新專案

  1. 在 Dashboard 點選 Create Project
  2. 輸入專案名稱，例如：flask-weather-app
  3. 點選 Create

3.3 部署 Web 應用

  1. 在專案頁面點選 Add Service
  2. 選擇 Git → 選擇你的 Repository flask-weather-app
  3. Zeabur 會自動偵測為 Python 專案並開始建置

等等！ 現在會建置失敗，因為還缺少資料庫與環境變數。

3.4 新增 PostgreSQL 服務

  1. 點選 Add Service → Marketplace
  2. 選擇 PostgreSQL
  3. 點選 Deploy

Zeabur 會自動建立 PostgreSQL 資料庫，並將 DATABASE_URL 注入到同專案的其他服務中。

3.5 新增 Redis 服務

  1. 點選 Add Service → Marketplace
  2. 選擇 Redis
  3. 點選 Deploy

Zeabur 會自動建立 Redis，並提供 REDIS_CONNECTION_STRING 環境變數。

3.8 觸發重新部署

  1. 點選 Deployments 標籤
  2. 點選 Redeploy 重新部署

等待建置完成（通常需要 2-3 分鐘）。

3.9 取得網址並測試

  1. 在 Networking 標籤中，Zeabur 會自動產生一個網址
  2. 點選該網址開啟你的應用程式
  3. 測試功能：
    • 搜尋城市天氣
    • 註冊/登入帳號
    • 收藏城市
    • 查看儀表板

4. 設定自訂網域（選用）

如果你有自己的網域，可以在 Networking 標籤中綁定：

  1. 點選 Add Domain
  2. 輸入你的網域（例如：weather.yourdomain.com）
  3. 依照指示設定 DNS CNAME 記錄
  4. Zeabur 會自動配置 SSL 憑證

5. 監控與日誌

5.1 查看應用程式日誌

在 Web Service 頁面：

  1. 點選 Logs 標籤
  2. 即時查看應用程式輸出與錯誤訊息

5.2 查看資源使用狀況

在 Metrics 標籤可以查看：

  • CPU 使用率
  • 記憶體使用量
  • 網路流量

6. 持續部署（CI/CD）

Zeabur 已經設定好自動部署：

  1. 每次 git push 到 GitHub
  2. Zeabur 會自動偵測變更
  3. 自動建置並部署新版本
  4. 零停機時間更新

7. 常見問題排除

7.1 部署失敗：找不到模組

原因：requirements.txt 缺少依賴套件

解決：

7.2 資料庫連線失敗

原因：環境變數未正確設定

解決：

  1. 檢查 DATABASE_URL 是否存在（應該自動注入）
  2. 確認 Web Service 與 PostgreSQL 在同一個專案中

7.3 限流不生效

原因：Redis 連線未設定

解決：

  1. 確認已新增 Redis 服務
  2. 確認環境變數 RATELIMIT_STORAGE_URI=${REDIS_CONNECTION_STRING} 設定正確
  3. 檢查日誌是否有 Redis 連線錯誤

7.4 靜態檔案載入失敗

原因：CDN 連線問題或 CSP 設定

解決：

  1. 檢查網路連線
  2. 確認 flask_weather/__init__.py 中 Talisman 的 CSP 設定為 None（已允許 CDN）

9. 安全性檢查清單

在正式上線前，確認以下項目：

  • ✅ SECRET_KEY 使用強隨機金鑰（不要使用 dev-secret-key）
  • ✅ FLASK_ENV=production（關閉除錯模式）
  • ✅ 環境變數不包含在 Git 中（.env 已加入 .gitignore）
  • ✅ API Key 妥善保管（不要硬編碼在程式中）
  • ✅ HTTPS 已啟用（Zeabur 自動配置）
  • ✅ Rate Limiting 已啟用（防止濫用）
  • ✅ CSRF 保護已啟用（Flask-WTF 自動處理）
