1. 預報 API 簡介

OpenWeatherMap 的免費方案提供了 5 Day / 3 Hour Forecast API。
這意味著它會回傳未來 5 天，每隔 3 小時一筆的資料（總共約 40 筆數據）。

API Endpoint: api.openweathermap.org/data/2.5/forecast
