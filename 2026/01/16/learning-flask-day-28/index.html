source code

1. 為什麼要使用 Docker？

Docker 可以將應用程式及其所有依賴環境打包成一個「容器」，確保在任何機器上（開發機、測試機、生產環境）都能一致地執行，解決了「在我的電腦上可以跑」的問題。

2. 前置條件

  • 已安裝 Docker 與 Docker Compose
  • 應用採用工廠模式：create_app() 函式
  • 已準備好 OpenWeather API Key

9. 常見問題排除

問題 原因 解決方案
ModuleNotFoundError 依賴未安裝 確認 requirements.txt 完整，重新 docker-compose up --build
應用無法連接資料庫 容器內 SQLite 路徑錯誤 確保掛載 volumes 正確，或使用絕對路徑
API Key 未被讀取 環境變數未設置 檢查 .env 檔案或手動 export
gunicorn 啟動失敗 factory function 參數錯誤 確認使用 flask_weather:create_app（無括號）
