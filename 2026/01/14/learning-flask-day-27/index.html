Day 27：整合測試 (Integration Testing)

1. 什麼是整合測試？

單元測試關注單一函數或類別，而整合測試則關注模組之間的互動。
在 Web 開發中，通常是指模擬使用者發送 HTTP 請求，檢查路由、模板渲染、資料庫操作是否正確串接。

4. Mocking 外部 API

在測試天氣查詢功能時，我們不應該真的去呼叫 OpenWeatherMap API，因為：

  • 速度慢。
  • 需要 API Key。
  • 網路可能不穩。
  • API 回傳資料會變動，導致測試不穩定。

我們使用 unittest.mock 來模擬 API 回應。

4.1 測試天氣查詢

重點提示：

  • 我們 mock 的是 flask_weather.weather.routes 中使用的函數（get_current_weather、get_forecast、get_air_pollution），而不是 requests.get
  • 這樣可以避免測試深入到 utils 層的實作細節
  • Mock 資料結構應與實際 API 回傳格式相符
