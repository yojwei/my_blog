這是 30 天學習 Flask 計畫 - Weather App 的 Day 14 詳細內容
source code

1. 為什麼需要快取？

目前每次使用者查詢天氣，我們都會向 OpenWeatherMap 發送請求。這有幾個問題：

  • API 限制：免費版 API 有呼叫次數限制。
  • 延遲：網路請求需要時間，影響使用者體驗。
  • 資源浪費：天氣資料通常不會在幾分鐘內劇烈變化，重複查詢相同資料是浪費。

Flask-Caching 可以幫我們將 API 回應暫存在記憶體（或 Redis）中，下次查詢相同城市時直接回傳，無需再次呼叫 API。
